# 🤖 Telegram Health Bot - Полностью Бесплатный Бот для Здоровья

## 🎯 Описание

Автоматический Telegram-бот, который генерирует и публикует качественный контент о здоровье, фитнесе и ЗОЖ каждые 2-4 часа. **Использует только бесплатные API** - никаких платных подписок!

## ✨ Возможности

### 🆓 100% Бесплатная Работа
- **Бесплатные AI модели**: Llama 3.3, Mixtral, Gemma через OpenRouter
- **Бесплатные изображения**: Pollinations.ai (без API ключа!)
- **Нулевые затраты**: Все API полностью бесплатны

### 🎨 Генерация Контента
- ✅ Автоматическая генерация текстов с помощью AI
- ✅ Создание изображений для постов
- ✅ SEO оптимизация и хэштеги
- ✅ Разнообразные темы: питание, фитнес, ментальное здоровье

### 📊 Аналитика
- ✅ Отслеживание эффективности постов
- ✅ Анализ популярных тем
- ✅ Рекомендации по оптимизации

### 🔄 Автоматизация
- ✅ Публикация по расписанию (каждые 2-4 часа)
- ✅ Автоматическое восстановление при сбоях
- ✅ Уведомления администратору

## 🚀 Быстрый Старт

### Шаг 1: Клонирование Репозитория

```bash
git clone https://github.com/santafreshden4ik-arch/telegram_health_bot.git
cd telegram_health_bot
```

### Шаг 2: Установка Зависимостей

```bash
pip install -r requirements.txt
```

### Шаг 3: Настройка .env

Скопируйте `.env.example` в `.env`:

```bash
copy .env.example .env
```

Заполните обязательные поля в `.env`:

```env
# Обязательные параметры
TELEGRAM_BOT_TOKEN=ваш_токен_от_botfather
TELEGRAM_CHANNEL_ID=@ваш_канал
TELEGRAM_ADMIN_CHAT_ID=ваш_telegram_id
OPENROUTER_API_KEY=ваш_ключ_openrouter
```

### Шаг 4: Получение API Ключей

#### 1. Telegram Bot Token (Обязательно)
1. Откройте [@BotFather](https://t.me/BotFather) в Telegram
2. Отправьте `/newbot`
3. Следуйте инструкциям
4. Скопируйте токен в `.env`

#### 2. Telegram Channel ID (Обязательно)
- Формат: `@your_channel` или `-1001234567890`
- **Важно**: Добавьте бота в канал как администратора!

#### 3. Ваш Telegram ID (Обязательно)
1. Откройте [@userinfobot](https://t.me/userinfobot)
2. Скопируйте ваш ID
3. Вставьте в `.env`

#### 4. OpenRouter API Key (Обязательно)
1. Зарегистрируйтесь на [OpenRouter.ai](https://openrouter.ai)
2. Перейдите в Settings → API Keys
3. Создайте новый ключ
4. Скопируйте в `.env`

**Бесплатные модели на OpenRouter:**
- `meta-llama/llama-3.3-70b-instruct:free`
- `mistralai/mixtral-8x7b-instruct`
- `google/gemma-2-9b-it:free`

#### 5. Hugging Face Token (Опционально)
1. Зарегистрируйтесь на [Hugging Face](https://huggingface.co)
2. Перейдите в Settings → Access Tokens
3. Создайте новый токен
4. Добавьте в `.env` (для fallback изображений)

### Шаг 5: Запуск Бота

```bash
# Windows
python main.py

# Или используйте bat файл
run_bot.bat
```

## 🔧 Устранение Проблем

### Бот не запускается

1. **Проверьте .env файл**:
   ```bash
   # Убедитесь, что все обязательные поля заполнены
   ```

2. **Проверьте токен бота**:
   - Токен должен быть от @BotFather
   - Формат: `1234567890:ABCdefGHIjklMNOpqrsTUVwxyz`

3. **Проверьте права бота**:
   - Бот должен быть администратором канала
   - Канал должен быть публичным или бот должен иметь доступ

### Ошибки генерации контента

1. **Проверьте OpenRouter API ключ**:
   - Зайдите на [OpenRouter.ai](https://openrouter.ai)
   - Проверьте, что ключ активен

2. **Проверьте интернет соединение**:
   ```bash
   ping openrouter.ai
   ```

### Изображения не генерируются

- **Pollinations.ai работает без ключа** - проверьте интернет
- Добавьте Hugging Face ключ для fallback

### Проверка логов

```bash
# Основные логи
type logs\bot.log

# Ошибки
type logs\error.log

# Аналитика
type logs\analytics.log
```

## 🎯 Рекомендации

### Для Максимальной Надежности

1. **Добавьте несколько API ключей** - бот автоматически переключится при сбое
2. **Используйте интервал 2-4 часа** - оптимально для вовлеченности
3. **Мониторьте логи** - проверяйте раз в день

### Для Лучшего Качества

1. **Настройте темы** под вашу аудиторию
2. **Используйте аналитику** для оптимизации
3. **Добавьте свои промпты** в `module_content.py`

### Для Экономии Ресурсов

1. **Используйте только Pollinations.ai** для изображений
2. **Увеличьте интервал** до 4-6 часов
3. **Отключите видео генерацию** (по умолчанию отключена)
