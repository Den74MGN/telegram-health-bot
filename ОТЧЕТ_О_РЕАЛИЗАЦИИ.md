### 4. Модуль `deduplicator.py` ✅

**Назначение**: Дедупликация контента (избежание повторов тем)

**Функциональность**:
- Проверка доступности темы
- Блокировка темы на N дней после использования
- Выбор следующей доступной темы
- Приоритизация тем

**Ключевые методы**:
```python
dedup.is_available(topic)             # Доступна ли тема
dedup.get_next_topic(topics)          # Следующая тема
dedup.filter_available(topics)        # Фильтр доступных
dedup.get_topic_priority(topics)      # Приоритеты
dedup.get_best_topic(topics)          # Лучшая тема
```

**Логика работы**:
1. Проверяет использовалась ли тема за последние N дней
2. Если да - блокирует тему
3. Выбирает следующую доступную тему
4. Если все заблокированы - выбирает с наименьшим использованием

**Тестирование**: ✅ Пройдено
- Проверка доступности: работает
- Блокировка после использования: работает
- Фильтрация доступных: корректна
- Выбор следующей темы: правильный
- Приоритизация: логичная

**Пример использования**:
```python
from database import Database
from deduplicator import Deduplicator

db = Database()
db.connect()

dedup = Deduplicator(db, block_days=7)

topics = ['фитнес', 'питание', 'йога']
next_topic = dedup.get_best_topic(topics)

db.close()
```

## 💻 Использование

### Быстрый Старт

```python
# 1. Импорты
from prompts import create_image_prompt
from optimizer import format_caption
from database import Database
from deduplicator import Deduplicator

# 2. Инициализация
db = Database('data/bot.db')
db.connect()
db.init_tables()

dedup = Deduplicator(db, block_days=7)

# 3. Выбор темы
topics = ['фитнес', 'питание', 'йога']
topic = dedup.get_best_topic(topics)

# 4. Генерация промпта
title = "5 упражнений для здоровья"
image_prompt = create_image_prompt(topic, title)

# 5. Форматирование текста
body = "Текст поста..."
hashtags = ['#здоровье', '#фитнес']
caption = format_caption(title, body, hashtags)

# 6. Сохранение
post_id = db.save_post(title, body, topic)

# 7. Закрытие
db.close()
```
