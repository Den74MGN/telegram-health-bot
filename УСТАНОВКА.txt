    📥 ИНСТРУКЦИЯ ПО УСТАНОВКЕ И ЗАПУСКУ
═══════════════════════════════════════════════════════════════

🔗 ШАГ 1: СКАЧАТЬ ПРОЕКТ
───────────────────────────────────────────────────────────────

Откройте браузер и перейдите:
https://github.com/santafreshden4ik-arch/telegram_health_bot

Нажмите зеленую кнопку "Code" → "Download ZIP"

Распакуйте архив в любую папку, например:
C:\Users\ВашеИмя\Documents\telegram_health_bot


💻 ШАГ 2: УСТАНОВИТЬ PYTHON
───────────────────────────────────────────────────────────────

Если Python не установлен:

1. Скачайте с https://www.python.org/downloads/
2. Запустите установщик
3. ✅ ВАЖНО: Поставьте галочку "Add Python to PATH"
4. Нажмите "Install Now"


📦 ШАГ 3: УСТАНОВИТЬ ЗАВИСИМОСТИ
───────────────────────────────────────────────────────────────

Откройте командную строку (Win+R → cmd)

Перейдите в папку проекта:
cd C:\Users\ВашеИмя\Documents\telegram_health_bot

Установите зависимости:
pip install -r requirements.txt


⚙️ ШАГ 4: НАСТРОИТЬ .ENV
───────────────────────────────────────────────────────────────

1. Скопируйте файл .env.example в .env:
   copy .env.example .env

2. Откройте .env в блокноте:
   notepad .env

3. Заполните 4 обязательных параметра:

   TELEGRAM_BOT_TOKEN=ваш_токен_от_botfather
   TELEGRAM_CHANNEL_ID=@ваш_канал
   TELEGRAM_ADMIN_CHAT_ID=ваш_telegram_id
   OPENROUTER_API_KEY=ваш_ключ_openrouter

4. Сохраните файл (Ctrl+S)


🔑 ШАГ 5: ПОЛУЧИТЬ API КЛЮЧИ
───────────────────────────────────────────────────────────────

A) TELEGRAM BOT TOKEN:
   1. Откройте Telegram
   2. Найдите @BotFather
   3. Отправьте /newbot
   4. Следуйте инструкциям
   5. Скопируйте токен

B) TELEGRAM CHANNEL ID:
   1. Создайте канал в Telegram
   2. Сделайте его публичным (например: @my_health_channel)
   3. Добавьте бота в канал как администратора
   4. Дайте боту права на публикацию

C) TELEGRAM ADMIN CHAT ID:
   1. Откройте @userinfobot в Telegram
   2. Скопируйте ваш ID

D) OPENROUTER API KEY:
   1. Откройте https://openrouter.ai
   2. Зарегистрируйтесь
   3. Перейдите в Settings → API Keys
   4. Создайте новый ключ
   5. Скопируйте ключ (начинается с sk-or-v1-)


✅ ШАГ 6: ПРОТЕСТИРОВАТЬ
───────────────────────────────────────────────────────────────

Проверьте настройки:
python test_setup.py

Должно показать:
✅ ВСЕ ТЕСТЫ ПРОЙДЕНЫ!


🚀 ШАГ 7: ЗАПУСТИТЬ БОТА
───────────────────────────────────────────────────────────────

ВАРИАНТ 1 - Тестовая публикация (рекомендуется):
python quick_post.py

Это создаст и опубликует один пост.
Проверьте ваш канал!

ВАРИАНТ 2 - Автоматический режим:
python main.py

Бот будет публиковать посты каждые 6 часов.

🆘 ПРОБЛЕМЫ?
═══════════════════════════════════════════════════════════════

Ошибка "Python не найден":
→ Установите Python с галочкой "Add to PATH"

Ошибка "pip не найден":
→ python -m pip install -r requirements.txt

Ошибка "Модуль не найден":
→ pip install --upgrade -r requirements.txt

Ошибка при публикации:
→ Проверьте что бот администратор канала
→ Проверьте ID канала (должен быть @channel или -100...)

Ошибка OpenRouter 404:
→ Создайте новый ключ на https://openrouter.ai/keys
