## Полезные Команды

```bash
# Быстрая диагностика
docker logs --tail 50 health-bot

# Проверка статуса
docker ps | grep health-bot

# Перезапуск при необходимости
docker restart health-bot

# Мониторинг ресурсов
docker stats health-bot
```
