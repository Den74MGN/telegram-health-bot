```
   ↓
9. Сбор аналитики (analytics)

10. Еженедельный отчет (analytics + notifications)
```

## 🎓 Как использовать

### Аналитика:
```python
from analytics import Analytics
from database import Database

db = Database()
db.connect()

analytics = Analytics(db)

# Получить статистику
total = analytics.get_total_posts()
top_topics = analytics.get_top_topics(5)
report = analytics.generate_report(days=7)

print(report)
```

### Уведомления:
```python
from notifications import NotificationManager

notifier = NotificationManager(admin_chat_id='YOUR_ID')

# Отправить уведомление о запуске
notifier.send_startup_notification()

# Отправить уведомление об успехе
notifier.send_success_notification('Заголовок', 'тема')

# Отправить аналитический отчет
notifier.send_analytics_report(analytics, days=7)
```
