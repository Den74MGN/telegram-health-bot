ШАГ 2: ИСПРАВЬТЕ OPENROUTER API КЛЮЧ
───────────────────────────────────────────────────────────────

Ошибка 404 означает, что ключ неверный или устарел.

1. Откройте https://openrouter.ai
2. Войдите в аккаунт
3. Перейдите в Settings → API Keys
4. Создайте НОВЫЙ ключ
5. Скопируйте его ПОЛНОСТЬЮ (начинается с sk-or-v1-)
6. Откройте файл .env
7. Замените старый ключ на новый:

   OPENROUTER_API_KEY=sk-or-v1-ваш_новый_ключ
