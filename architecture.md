# Системная Архитектура

## Обзор

Telegram Бот Здоровья - это модульная, событийно-ориентированная система, которая автоматизирует создание и публикацию контента по темам здоровья и wellness. Архитектура следует подходу микросервисов с отдельными модулями для разных ответственностей.

## Компоненты

### 1. Модуль Генерации Контента (module_content.py)
- **Назначение**: Генерирует текстовый и видео контент с использованием ИИ-сервисов
- **Входы**: Тематические подсказки, шаблоны контента
- **Выходы**: Структурированные объекты контента (текстовые посты, видеофайлы)
- **Зависимости**: OpenAI API, библиотека MoviePy

### 2. Модуль Планировщика (module_scheduler.py)
- **Назначение**: Управляет временным выполнением генерации контента и публикации
- **Входы**: Конфигурация расписания (каждые 2 часа)
- **Выходы**: Триггеры для задач генерации контента и публикации
- **Зависимости**: Библиотека APScheduler

### 3. Модуль Публикации (module_publisher.py)
- **Назначение**: Обрабатывает публикацию в Telegram-каналы с обработкой ошибок
- **Входы**: Объекты контента, данные рекламы, конфигурация канала
- **Выходы**: Опубликованные посты, уведомления об ошибках
- **Зависимости**: Библиотека python-telegram-bot

### 4. Модуль Интеграции Рекламы (module_ads.py)
- **Назначение**: Получает и интегрирует рекламу с платформы Telega.in
- **Входы**: API учетные данные, правила размещения рекламы
- **Выходы**: Объекты рекламного контента для вставки в посты
- **Зависимости**: Библиотека requests для API вызовов

### 5. Главное Приложение (main.py)
- **Назначение**: Оркестрирует все модули и обрабатывает конфигурацию
- **Входы**: Переменные окружения, конфигурационные файлы
- **Выходы**: Системные логи, уведомления администратора
- **Зависимости**: Все модули, конфигурация логирования

## Поток Данных

1. **Триггер Планировщика** → Модуль Генерации Контента
2. **Генерация Контента** → Модуль Интеграции Рекламы (для вставки рекламы)
3. **Контент + Реклама** → Модуль Публикации
4. **Публикация** → Telegram Канал
5. **Ошибки/Логи** → Админ Чат (через Модуль Публикации)

## Внешние Сервисы

- **Telegram Bot API**: Для публикации в каналы и уведомлений администратора
- **OpenAI API**: Для генерации текстового контента (бесплатный тариф)
- **Telega.in API**: Для получения рекламы
- **API Стокового Видео**: Для генерации видео (бесплатный стоковый контент)

## Обработка Ошибок

- **Таймауты API**: Повтор с экспоненциальной задержкой
- **Ограничения Скорости**: Очередь запросов и соблюдение лимитов
- **Сбои Генерации Контента**: Запасной вариант с кэшированным контентом
- **Ошибки Публикации**: Логирование и уведомление админа, пропуск неудачных постов

## Мониторинг

- **Логирование**: Структурированные логи в файл и консоль
- **Проверки Здоровья**: Периодические самопроверки подключения к API
- **Уведомления Администратора**: Оповещения об ошибках в Telegram чат админа
- **Метрики**: Уровень успешности генерации контента, статистика публикаций

## Безопасность

- **API Ключи**: Хранятся как переменные окружения
- **Ограничение Скорости**: Встроенное соблюдение всех лимитов API
- **Валидация Входа**: Очистка всех внешних входов
- **Маскировка Ошибок**: Не раскрывать чувствительную информацию в логах

## Масштабируемость

- **Модульный Дизайн**: Легко расширять новыми типами контента
- **Асинхронные Операции**: Неблокирующий I/O для API вызовов
- **Управление Ресурсами**: Эффективное использование памяти для обработки видео
- **Настраиваемые Лимиты**: Регулируемая частота публикаций и объем контента
