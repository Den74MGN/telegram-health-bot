## 📝 Инструкции по Запуску

### Шаг 1: Установка Зависимостей
```bash
pip install -r requirements.txt
```

### Шаг 2: Настройка .env
```bash
# Скопируйте .env.example в .env
copy .env.example .env

# Заполните обязательные поля:
TELEGRAM_BOT_TOKEN=your_token_from_botfather
TELEGRAM_CHANNEL_ID=@your_channel_username
TELEGRAM_ADMIN_CHAT_ID=your_telegram_user_id
OPENROUTER_API_KEY=your_openrouter_key
```

### Шаг 3: Получение API Ключей (Все Бесплатно!)

#### OpenRouter (Обязательно)
1. Зарегистрируйтесь на https://openrouter.ai
2. Получите бесплатный API ключ
3. Доступны модели: Llama 3.3, Mixtral, Gemma (бесплатно!)

#### Hugging Face (Опционально)
1. Зарегистрируйтесь на https://huggingface.co
2. Создайте токен в Settings → Access Tokens
3. Добавьте в .env: `HUGGINGFACE_API_KEY=your_token`

#### Google Gemini (Опционально)
1. Получите ключ на https://makersuite.google.com/app/apikey
2. Добавьте в .env: `GOOGLE_GEMINI_API_KEY=your_key`

### Шаг 4: Запуск Бота
```bash
# Windows
python main.py

# Или используйте bat файл
run_bot.bat
```

## 🎯 Рекомендации по Использованию

### Для Максимальной Надежности
1. **Используйте несколько API ключей** - бот автоматически переключится при сбое
2. **Настройте интервал публикации** - рекомендуется 2-4 часа
3. **Мониторьте логи** - проверяйте `logs/bot.log` на ошибки

### Для Лучшего Качества Контента
1. **Добавьте свои темы** в `module_content.py` → `self.topics`
2. **Настройте промпты** для вашей аудитории
3. **Используйте аналитику** для оптимизации

### Для Экономии Ресурсов
1. **Отключите генерацию видео** (требует много ресурсов)
2. **Используйте только Pollinations.ai** для изображений (не требует API ключа)
3. **Увеличьте интервал публикации** до 4-6 часов
