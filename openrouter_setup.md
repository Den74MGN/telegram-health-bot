# 🚀 Настройка OpenRouter для Бесплатных ИИ Моделей

## Что такое OpenRouter?

**OpenRouter** - это платформа, предоставляющая доступ к множеству ИИ моделей БЕСПЛАТНО. В отличие от OpenAI, здесь нет ежемесячных платежей и лимитов.

## Преимущества OpenRouter

✅ **Полностью бесплатно** для большинства моделей
✅ **Доступ к топовым моделям**: Llama, Mixtral, Claude, Gemma
✅ **Нет лимитов на использование** для бесплатных моделей
✅ **Простая интеграция** через единый API
✅ **Высокая надежность** и скорость

## Регистрация в OpenRouter

### Шаг 1: Создание Аккаунта

1. Перейдите на сайт: **https://openrouter.ai/**
2. Нажмите "Sign Up" или "Get Started"
3. Зарегистрируйтесь через:
   - Email
   - Google аккаунт
   - GitHub аккаунт

### Шаг 2: Получение API Ключа

1. После регистрации зайдите в личный кабинет
2. Перейдите в раздел **"API Keys"** или **"Keys"**
3. Нажмите **"Create Key"** или **"+"**
4. Придумайте название ключа (например: "telegram-bot")
5. Скопируйте сгенерированный ключ

**Формат ключа:** `sk-or-v1-...` (начинается с sk-or-v1-)

### Шаг 3: Пополнение Баланса (Опционально)

Хотя основные модели бесплатны, для премиум моделей можно пополнить баланс:

1. Зайдите в **"Billing"** или **"Credits"**
2. Нажмите **"Add Credits"**
3. Минимальная сумма: $5
4. Оплата картой или криптовалютой

**Важно:** Для базовой работы бота пополнение НЕ ТРЕБУЕТСЯ!

## Настройка в Боте

### Шаг 4: Добавление Ключа в Конфигурацию

Откройте файл `.env` и добавьте:

```env
# OpenRouter Configuration (Бесплатные ИИ модели)
OPENROUTER_API_KEY=sk-or-v1-your-key-here
```

### Шаг 5: Проверка Работы

```python
# Тест бесплатных моделей
from module_content import ContentGenerator

# Инициализация с вашим ключом
generator = ContentGenerator("sk-or-v1-your-key-here")

# Тест генерации
import asyncio

async def test():
    content = await generator.generate_text_post("здоровье")
    print("✅ Генерация работает!")
    print(f"Заголовок: {content['title']}")
    print(f"Текст: {content['body'][:100]}...")

asyncio.run(test())
```

## Поиск и Решение Проблем

### Проблема: "Invalid API Key"
**Решение:**
1. Убедитесь, что ключ начинается с `sk-or-v1-`
2. Проверьте, что ключ скопирован полностью
3. Убедитесь, что аккаунт активирован

### Проблема: "Model not available"
**Решение:**
1. Проверьте название модели в документации OpenRouter
2. Попробуйте альтернативную модель
3. Обновите список доступных моделей

### Проблема: "Rate limit exceeded"
**Решение:**
1. Добавьте задержку между запросами
2. Используйте разные модели для распределения нагрузки
3. Включите кэширование результатов
