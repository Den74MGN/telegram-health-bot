## 📦 СТРУКТУРА МОДУЛЯ

### Класс: `DatabaseManager`

**Основные методы:**

1. **`__init__(db_path)`** - Инициализация менеджера БД
2. **`init_database()`** - Создание таблиц и индексов
3. **`save_post(post_data)`** - Сохранение поста
4. **`get_recent_posts(limit)`** - Получение последних постов
5. **`check_topic_availability(topic, block_days)`** - Проверка доступности темы
6. **`get_topic_statistics()`** - Статистика по темам
7. **`get_available_topics(all_topics, block_days)`** - Список доступных тем
8. **`update_post_metrics(post_id, views, reactions, shares)`** - Обновление метрик
9. **`get_total_posts()`** - Общее количество постов
10. **`backup_database(backup_path)`** - Резервное копирование

## 🗄️ СТРУКТУРА БАЗЫ ДАННЫХ

### Таблица: `posts`

```sql
CREATE TABLE posts (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    title TEXT NOT NULL,
    body TEXT NOT NULL,
    topic TEXT NOT NULL,
    hashtags TEXT,                    -- JSON массив
    seo_keywords TEXT,                -- JSON массив
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    published_at TIMESTAMP,
    views INTEGER DEFAULT 0,
    reactions INTEGER DEFAULT 0,
    shares INTEGER DEFAULT 0,
    image_generated BOOLEAN DEFAULT 0,
    status TEXT DEFAULT 'published'
)
```

**Назначение:** Хранение всех опубликованных постов

---

### Таблица: `topics`

```sql
CREATE TABLE topics (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    name TEXT UNIQUE NOT NULL,
    last_used TIMESTAMP,
    usage_count INTEGER DEFAULT 0,
    avg_views REAL DEFAULT 0,
    avg_reactions REAL DEFAULT 0,
    priority INTEGER DEFAULT 0
)
```

**Назначение:** Отслеживание использования тем и их эффективности

---

### Таблица: `analytics`

```sql
CREATE TABLE analytics (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    post_id INTEGER,
    metric_name TEXT NOT NULL,
    metric_value REAL NOT NULL,
    recorded_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (post_id) REFERENCES posts (id)
)
```

**Назначение:** Детальная аналитика по постам

---

### Индексы для оптимизации:

```sql
CREATE INDEX idx_posts_topic ON posts(topic);
CREATE INDEX idx_posts_published_at ON posts(published_at);
CREATE INDEX idx_topics_last_used ON topics(last_used);
```

## 🔗 ИНТЕГРАЦИЯ В ПРОЕКТ

### Изменения в `start.py`:

#### 1. Импорт модуля:
```python
from database_manager import DatabaseManager
```

#### 2. Инициализация:
```python
# Инициализация базы данных
db_manager = DatabaseManager('data/bot.db')
db_manager.init_database()
print("✅ База данных инициализирована")
```

#### 3. Выбор темы с учетом БД:
```python
# Получаем доступные темы из БД (не использовались последние 7 дней)
all_topics = content_gen.topics
available_topics = db_manager.get_available_topics(all_topics, block_days=7)

# Выбираем случайную доступную тему
import random
topic = random.choice(available_topics) if available_topics else random.choice(all_topics)

content = content_gen.generate_text_post(topic)
```

#### 4. Сохранение поста:
```python
if success:
    stats['posts_published'] += 1
    print(f"✅ Пост #{stats['posts_published']} опубликован")
    
    # Сохраняем пост в БД
    try:
        post_id = db_manager.save_post(content)
        print(f"💾 Пост сохранен в БД (ID: {post_id})")
    except Exception as e:
        print(f"⚠️ Ошибка сохранения в БД: {e}")
```

#### 5. Статистика при остановке:
```python
except KeyboardInterrupt:
    print("\n\n🛑 Бот остановлен пользователем")
    print(f"📊 Всего опубликовано постов: {stats['posts_published']}")
    print(f"⏱️ Время работы: {datetime.now() - stats['start_time']}")
    
    # Показываем статистику из БД
    total_posts = db_manager.get_total_posts()
    print(f"💾 Всего постов в БД: {total_posts}")
    
    # Создаем резервную копию
    backup_path = db_manager.backup_database()
    if backup_path:
        print(f"💾 Резервная копия БД: {backup_path}")
```
