# 📋 План Улучшений Проекта Telegram Health Bot

## 🎯 Приоритет 1 - Критичные Улучшения

### 1. ✅ Улучшить промпт для генерации изображений
**Текущая проблема:**
- Простые промпты дают низкое качество
- Иногда неправильная анатомия людей
- Недостаточно деталей для реалистичности

**Что нужно сделать:**
- Добавить больше деталей в промпты (освещение, композиция, стиль)
- Указывать "photorealistic, professional photography, 8k"
- Для людей: "correct human anatomy, natural poses, proper proportions"
- Для каждой темы свой специализированный промпт
- Добавить негативные промпты (что НЕ показывать)

**Пример улучшенного промпта:**
```
Professional health photography: [тема]. 
High quality, photorealistic, 8k resolution, 
professional studio lighting, correct human anatomy,
natural poses, vibrant colors, magazine quality,
clean composition, modern aesthetic.
Negative: cartoon, anime, distorted, unrealistic
```

---

### 2. ✅ Улучшить генерацию текста под количество символов в Telegram
**Текущая проблема:**
- Telegram ограничивает caption до 1024 символов
- Тексты часто обрезаются
- Неоптимальная структура для мобильных устройств

**Что нужно сделать:**
- Генерировать текст строго 600-800 символов
- Добавить в промпт: "ВАЖНО: максимум 600 символов!"
- Структура: Заголовок (50) + Текст (600) + Хэштеги (50) = 700 символов
- Короткие абзацы (2-3 предложения)
- Нумерованные списки для лучшей читаемости
- Проверка длины перед отправкой

**Улучшенный промпт для текста:**
```
Напиши статью о [тема] для Telegram.

СТРОГОЕ ОГРАНИЧЕНИЕ: 600 символов максимум!

Структура:
- Вступление (2 предложения)
- 3-5 коротких советов
- Призыв к действию (1 предложение)

Используй эмодзи: 💪🥗🧘‍♀️
Короткие абзацы!
```

### 4. Улучшить систему аналитики
**Текущая проблема:**

**Что делать:**

### 5. Добавить дедупликацию контента
**Зачем:**
- Избежать повторения тем
- Разнообразие контента
- Лучшая вовлеченность

**Что делать:**

### 6. Улучшить обработку ошибок
**Текущая проблема:**
- Event loop закрывается между вызовами
- Pool timeout при частых запросах
- Нет автоматического восстановления

**Что делать:**
- Единый event loop для всех операций
- Увеличить connection pool
- Автоматический retry с экспоненциальной задержкой
- Fallback на альтернативные API
